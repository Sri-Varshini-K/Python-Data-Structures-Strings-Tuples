# Python – Data Structures: Strings & Tuples

## Project Overview

This assignment focuses on understanding Python's fundamental data structures, particularly Strings and Tuples. It covers string manipulation techniques and tuple operations through practical Python programming exercises.

## Objectives

- Understand string concatenation and manipulation.
- Perform string slicing and indexing.
- Apply built-in string methods.
- Create and combine tuples.
- Perform tuple repetition and slicing.
- Access individual tuple elements.

## Concepts Covered

### 1. Strings
- String Concatenation
- String Indexing
- String Slicing
- String Reversal
- String Methods:
  - `upper()`
  - `lower()`
  - `capitalize()`
  - `count()`
  - `replace()`

### 2. Tuples
- Tuple Creation
- Tuple Concatenation
- Tuple Repetition
- Element Access
- Tuple Slicing
